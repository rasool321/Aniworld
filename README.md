
# AniWorld

AniWorld is a simple front-end anime movie listing website made using **HTML**, **CSS**, and **JavaScript**. It's designed for showcasing anime content in a clean and organized layout for fans and users alike.

---

## 🔥 Features

- 🎬 **Anime Movie Listings**: Displays name, genre, duration, language, and ratings.
- ✨ **Responsive Design**: Modern UI that adapts to various screen sizes.
- 🔐 **Login Modal**: Includes an avatar and 'Remember me' option.
- 💡 **Forgot Password Section**: Provides a friendly hint for users.
- 📱 **Mobile-Friendly Structure**: Optimized for mobile devices.

---

## 💻 Technologies Used

- **HTML**
- **CSS**
- **JavaScript**
